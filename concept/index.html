Why This Feels More Modern

This is the design logic behind the example, not just a random restyle.

It uses stronger type contrast, fewer generic boxes, more deliberate spacing, and clearer “feature” areas so the page feels curated instead of assembled.

It also lets the page support both sides of what you actually are: a marathon run archive and a sporadic creator/streamer, without pretending it needs to look like a daily content machine.
